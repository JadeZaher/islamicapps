# Unified Dataset Snapshots

Point-in-time snapshots of the fully consolidated hadith dataset from April 20, 2026.
These predate the Zaydi collection addition and chapter name cleanup.

## Files

| File | Description | Size |
|------|-------------|------|
| `unified_hadith_consolidated.csv` | Full consolidated CSV (all traditions) | 140 MB |
| `unified_hadith_consolidated.csv.gz` | Compressed version | 32 MB |
| `unified_hadith_collection_2026-04-20_enhanced.xlsx` | Excel export with enhanced metadata | 41 MB |
| `cross_reference_mapping.csv` | Cross-tradition parallel hadith mapping | 1.9 MB |

## Note

The current active datasets are `all_hadiths_clean.csv` and `all_hadiths_shia.csv`
in the parent `hadith-data/` directory. These snapshots are kept for reference.
