# Corpus filter identity

Source filters expand a canonical work name only to exact historical labels that identify that same work unambiguously. A label shared by multiple works, including legacy `Al-Amālī` and `Kitāb al-Ghayba`, remains its own unresolved filter option; it must never be silently assigned to a compiler.

Tradition aliases are read compatibility for live and bookmarked values. The URL should converge on `Sunni`, `Imami`, `Zaydi`, or `Ibadi` after the next user change, while queries continue to accept known legacy strings.
